Architektur & Funktionsweise

Was ist HAULITZ?

0% Halluzinationen

HAULITZ ist eine deterministische Verifizierungs-Schutzschranke für unternehmensweite ERP-Systeme (SAP S/4HANA, Microsoft Dynamics 365, Oracle Cloud ERP). In einer Zeit, in der Unternehmen zunehmend auf generative KI und probabilistische LLMs zur Dokumentenerfassung setzen, entstehen gravierende finanzielle und rechtliche Risiken: Sprachmodelle halluzinieren Vorsteuer-Rechenschritte (§ 14 UStG), übersehen fehlerhafte Container-Prüfziffern (ISO 6346) und akzeptieren unbemerkt Lieferanten-Kurzlieferungen oder Preisaufschläge (HGB § 377).

HAULITZ schaltet sich als kompromisslose mathematische Firewall vor das ERP-Staging. Jeder Beleg wird auf den Cent genau geprüft, gegen geltendes deutsches und europäisches Handelsrecht abgeglichen und mit einer unveränderlichen GoBD § 147 AO SHA-256 Hash-Kette in unserer Frankfurter Datenbank (AWS eu-central-1) revisionssicher versiegelt.

Deterministische Präzision
Keine probabilistischen Schätzungen. Exakte Cent-Arithmetik, Modulo-97 (IBAN), Modulo-11 (ISO 6346) und Modulo-10 (GS1 EAN-13) Prüfziffernprüfungen.
GoBD § 147 AO Hash-Kette
Jeder Prüflauf wird kryptografisch mit dem vorherigen Siegel verknüpft und unveränderbar in Frankfurt auf AWS eu-central-1 festgeschrieben.
Staging Armor für SAP
Automatische Quarantäne fehlerhafter Datensätze, Abwehr von SQL-Injections (OWASP ASVS) und sofortige Erstellung gesetzlicher Mängelrügen per Resend.

-- Microsoft SQL Server 2022 / SAP Side-Car Staging
CREATE OR ALTER PROCEDURE sp_Haulitz_StageVerifiedDocument
    @p_DomainId VARCHAR(50),
    @p_DocumentRef VARCHAR(100),
    @p_GrossAmount DECIMAL(18, 4),
    @p_VatAmount DECIMAL(18, 4),
    @p_Sha256Seal CHAR(64),
    @p_PreviousSeal CHAR(64)
AS
BEGIN
    SET NOCOUNT ON;
    -- GoBD § 147 AO: Verify seal chain integrity before insert
    INSERT INTO dbo.STAGING_INVOICE_INBOUND (
        DomainId, DocumentRef, GrossAmount, VatAmount,
        Sha256Seal, PreviousSeal, Status, StagedAt
    )
    VALUES (
        @p_DomainId, @p_DocumentRef, @p_GrossAmount, @p_VatAmount,
        @p_Sha256Seal, @p_PreviousSeal, 'AUTHORIZED_FOR_POSTING', SYSUTCDATETIME()
    );
END;
2. C# .NET 8 Enterprise Ingestion SDK

// Haulitz Gateway C# .NET 8 Client SDK
public class HaulitzVerificationGateway
{
    private readonly HttpClient _httpClient;
    private const string FrankfurtGateway = "https://haulitz.allensimeonfletcher.workers.dev/api";

    public HaulitzVerificationGateway(HttpClient httpClient) => _httpClient = httpClient;

    public async Task CommitAuditAsync(AuditRecord record)
    {
        var response = await _httpClient.PostAsJsonAsync($"{FrankfurtGateway}/audit", record);
        response.EnsureSuccessStatusCode();
        return await response.Content.ReadFromJsonAsync();
    }
}
