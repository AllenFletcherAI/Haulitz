HAULITZ — Verifizierungs-Gateway für Geschäftsbelege

Automatische Cent-Prüfung, Steuerberechnung nach § 14 UStG und HGB § 377 sowie Prüfziffern-Validierung vor dem Eintrag in ERP-Systeme.

Was ist HAULITZ?

Code-basierte Validierung

HAULITZ ist eine automatisierte Prüfschicht für geschäftliche Belege wie Eingangsrechnungen, Frachtbriefe und Lieferscheine. Anstatt Belegdaten ungeprüft in Datenbanken oder ERP-Systeme einzupflegen, führt HAULITZ mathematische Summenprüfungen und Prüfziffern-Algorithmen durch.

Gültige Belege werden mit einem SHA-256 Prüfsiegel in der PostgreSQL-Audit-Datenbank in Frankfurt (AWS eu-central-1) protokolliert. Rechnerische Differenzen oder falsche Prüfziffern werden gestoppt, bevor Zahlungen ausgelöst werden.

Exakte Arithmetik
Cent-genaue Berechnung von Zwischensummen, Steuersätzen (§ 14 UStG) und Prüfziffern (IBAN Modulo-97, ISO 6346, GS1 EAN-13).
Audit-Protokoll
Jeder Prüflauf wird mit einem SHA-256 Hash und Zeitstempel unveränderbar in PostgreSQL dokumentiert.
Strukturierte Mängelrügen
Rechnerische Differenzen und Formfehler erzeugen strukturierte Beanstandungen zur schnellen Klärung mit Lieferanten.

1. SAP S/4HANA Staging Procedure (T-SQL)

Revisionssichere gespeicherte Prozedur zur Übergabe verifizierter Belege an das SAP-Zwischenlager. 

-- Microsoft SQL Server 2022 / SAP Side-Car Staging
CREATE OR ALTER PROCEDURE sp_Haulitz_StageVerifiedDocument
    @p_DomainId VARCHAR(50),
    @p_DocumentRef VARCHAR(100),
    @p_GrossAmount DECIMAL(18, 4),
    @p_VatAmount DECIMAL(18, 4),
    @p_Sha256Seal CHAR(64),
    @p_PreviousSeal CHAR(64)
AS
BEGIN
    SET NOCOUNT ON;
    -- GoBD § 147 AO: Verify seal chain integrity before insert
    INSERT INTO dbo.STAGING_INVOICE_INBOUND (
        DomainId, DocumentRef, GrossAmount, VatAmount,
        Sha256Seal, PreviousSeal, Status, StagedAt
    )
    VALUES (
        @p_DomainId, @p_DocumentRef, @p_GrossAmount, @p_VatAmount,
        @p_Sha256Seal, @p_PreviousSeal, 'AUTHORIZED_FOR_POSTING', SYSUTCDATETIME()
    );
END;
2. C# .NET 8 Enterprise Ingestion SDK

Hochperformanter Microservice-Client zur deterministischen Vorabprüfung im Backend. 

// Haulitz Gateway C# .NET 8 Client SDK
public class HaulitzVerificationGateway
{
    private readonly HttpClient _httpClient;
    private const string FrankfurtGateway = "https://haulitz.allensimeonfletcher.workers.dev/api";

    public HaulitzVerificationGateway(HttpClient httpClient) => _httpClient = httpClient;

    public async Task CommitAuditAsync(AuditRecord record)
    {
        var response = await _httpClient.PostAsJsonAsync($"{FrankfurtGateway}/audit", record);
        response.EnsureSuccessStatusCode();
        return await response.Content.ReadFromJsonAsync();
    }
}
